## 💻 Sobre o Projeto

O Helpdesk é uma aplicação front-end construída com foco na experiência do utilizador e na performance. A arquitetura foi pensada para garantir uma interface fluida, onde as mudanças de estado dos chamados (Aberto, Em Progresso, Fechado) ocorrem de forma imediata e previsível.

> **Nota:** Adicionar Screenshot da aplicação a funcionar.

## ✨ Principais Funcionalidades

- **Gestão de Estado Complexa:** Controle preciso do ciclo de vida dos tickets.
- **Tipagem Rigorosa:** Utilização de TypeScript para prevenir erros de *runtime* e garantir a integridade dos dados trafegados na interface.
- **Prevenção de Erros (QA Mindset):** Validação antecipada de formulários e tratamento adequado de *edge cases*.
- **Interface Responsiva:** Design limpo e adaptável desenvolvido com Tailwind CSS.
